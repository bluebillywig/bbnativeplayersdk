# Release Notes

## v8.37.0 (2025-10-27)

### Features

* The CTA text in Shorts is now more customisable by selecting a button text source.
* Updated and improved the display of start, pause and endscreens.
* Related items with deviating aspect ratios now show better.
* Duration customisation options (background color and play icon) for Shorts shelves are now supported.
* Outline colors for unwatched clips in Shorts shelves are now also supported.
